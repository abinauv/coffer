# Getting help with Coffer

Coffer is free, open-source software maintained by one person. There is
no paid support and no service-level agreement — but there is a right place for each kind
of question, and using it gets you an answer faster.

## Before you ask

- The [README](./README.md) answers the common questions — what Coffer does today, what it
  does not do yet, GST support, where your data lives, and what happens if you forget a
  passphrase — in its **Frequently asked questions** section.
- [`docs/`](./docs/README.md) covers building from source, the architecture, the data
  model and security.
- [`docs/security-for-users.md`](./docs/security-for-users.md) covers passphrases, recovery
  codes and verifying a download.

## Where to go

| You want to…                                         | Go to                                                                                                                    |
| ---------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| Ask how to do something, or whether Coffer can do it | [GitHub Discussions → Q&A](https://github.com/abinauv/coffer/discussions)                                                |
| Suggest a feature or share an idea                   | [GitHub Discussions → Ideas](https://github.com/abinauv/coffer/discussions)                                              |
| Report something that is broken                      | [A bug report](https://github.com/abinauv/coffer/issues/new/choose) — the template asks for what we need to reproduce it |
| Report a security vulnerability                      | **Privately**, as [`SECURITY.md`](./SECURITY.md) describes. Never in a public issue or discussion.                       |
| Report a figure that is wrong                        | A bug report, marked as such. Quietly wrong numbers are treated as seriously as a crash.                                 |
| Report behaviour that breaks the Code of Conduct     | By e-mail, as [`CODE_OF_CONDUCT.md`](./CODE_OF_CONDUCT.md) describes                                                     |
| Contribute code or a tax regime                      | [`CONTRIBUTING.md`](./CONTRIBUTING.md), then [`docs/adding-a-tax-regime.md`](./docs/adding-a-tax-regime.md) for a regime |

## What not to post publicly

Never paste a company file, a backup archive, a passphrase, a recovery code, or real
customer, bank or GST details into an issue or a discussion. If a problem only reproduces
with real data, say so, and we will work out a private way to look at it.

## Accounting and tax advice

Coffer keeps books; it does not give professional advice. For how a transaction should be
treated under GST or the Income Tax Act, ask a chartered accountant or tax practitioner.
